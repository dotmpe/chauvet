# Chauvet theme project history

[2022-02-19] Started an earthy/mossy theme but with some bold (yellow and blue)
for accents.

Inspired by muted colors of Vim themes like desert, but combined with accents
like the bold green of Mustang (that comes with Powerline configurations), but
using an alternative palette of accents around yellow-amber and blue-purple
instead of green.

The name Chauvet itself is intended to hearken back to the caves of Chauvet, a
protected (and elsewhere replicated) place in France where many of the most
ancient black (and some red ochre) wall paintings and impressions are preserved;
hundred of drawings depicting scenes of many animals, and as seen and drawn by
the Aurignacian (32-30kya) and Gravettian (27-25kya) era people. [WP 2026]

The 'Chauvet steppe wisent' is among if not the most copied and recognizable
ancient cave painting.

[2022-05-22] Started parent project to the Vim theme, and a separate project for
tmux. Intend to move more into science and as well cross-format/app themeing in
Chauvet project now.

For now, using copies of X11 palette swatches mostly for Chauvet, but intend to
make this more parametric, and specifically tuned into a matching set of 24 bit
values sometime. (But perhaps only after if I calibrate my setup, when "true"
colorspace selection actually makes sense. Or more sense.)

Adding colors found also while using BunsenLabs Boron (a Debian 12/Bookworm
distro, follow-up on CrunchBang for low-resource devices), that offer a few nice
selections.

[2026-10-12] Updating project to new file (src, doc) structure, cleaning out
some old dev notes. Adding more third party, in particular Nord (nordtheme.com)
as perhaps an inspiration to harmonize BL Boron themes. And also as a very
well-setup reference project, that has many specific distributables.
